## H. Lead/lag

Частота локального получения Polymarket и Limitless различается; Limitless публикует coalesced full books. Разный batching, пустые интервалы, buffering и resync не позволяют приписать площадке причинное лидерство. Network latency не измерялась. Для оценки lead/lag нужны более длинный синхронный sample, контроль processing backlog и анализ сдвигов по однотипным изменениям котировок.

До многосуточного запуска — writer queue/backlog, crash recovery, disk quota и проверка нескольких часов.
