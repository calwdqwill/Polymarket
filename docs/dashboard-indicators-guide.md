# Гайд по индикаторам dashboard

Этот документ описывает все основные индикаторы и элементы управления в `Crypto imbalance dashboard`.

Dashboard сейчас работает с тремя источниками:

- `Binance historical` - исторический fallback по публичным Binance Spot klines.
- `Chainlink accumulated realtime` - локально накопленные realtime-свечи из Chainlink Streams latest reports.
- `Chainlink Candlestick API` - целевой historical-источник Chainlink, сейчас заблокирован авторизацией `HTTP 401`.

Важно: `Chainlink accumulated realtime` не является полноценным историческим backfill. Он содержит только те 5-минутные окна, которые локальный worker успел собрать, пока был запущен. Пропущенные окна нельзя восстановить через latest-report endpoint.

## Верхняя карточка

### Asset / timeframe

Показывает выбранный актив и таймфрейм, например `BTC / 5m`.

Сейчас все расчеты dashboard привязаны к 5-минутным свечам.

### Source note

Короткая подсказка по выбранному источнику:

- `90d fallback` - исторические свечи из Binance fallback.
- `local worker` - локально накопленный Chainlink realtime.
- `requires auth` - Chainlink Candlestick API требует рабочей авторизации.

### Data ready / no data

Показывает, есть ли свечи в текущей выборке.

- `data ready` - backend вернул хотя бы одну свечу.
- `no data` - для выбранного источника, периода и актива свечей нет.

### Цена

Большое значение в карточке - `close` последней свечи в текущей выборке.

Если свечей нет, отображается `n/a`.

### Процент под ценой

Изменение цены за выбранный период:

```text
(last.close - first.open) / first.open * 100
```

Зеленый цвет означает положительное изменение, красный - отрицательное.

### Candles

Количество свечей, загруженных для выбранного актива, периода и источника.

Для Binance historical число обычно большое. Для Chainlink accumulated realtime число растет только пока запущен worker.

### Events

Количество imbalance events по выбранному активу и текущим фильтрам.

Если выбран высокий `Severity`, конкретный `Event type` или маленький период, событий может быть мало или не быть совсем.

### Source label

Человеческое название выбранного источника данных.

### Sparkline

Мини-график закрытий (`close`) по текущей выборке. Он нужен для быстрого визуального понимания направления движения без чтения полной свечной панели.

## Карточки активов BTC / ETH / SOL

Каждая карточка показывает:

- последний `close` по активу;
- изменение за выбранный период;
- количество свечей;
- количество событий.

Клик по карточке переключает актив в dashboard.

## Source status

Плашка появляется, когда источник требует пояснения.

### Chainlink accumulated realtime

Плашка сообщает, что realtime-свечей пока мало или worker был не свежим.

Фраза `Missed windows cannot be reconstructed from the latest-report endpoint` означает: если worker не работал, Chainlink latest report не отдаст все пропущенные 5-минутные свечи задним числом.

### Chainlink Candlestick API

Плашка сообщает, что historical Chainlink Candlestick API сейчас не загрузил свечи из-за авторизации `HTTP 401`.

Это отдельный источник, не то же самое, что `Chainlink accumulated realtime`.

## Фильтры

### Period

Выбор временного окна:

- `1D`;
- `3D`;
- `7D`;
- `14D`.

Фильтр влияет на свечи, события, карточки активов, график, таблицы и heatmap.

### Source

Выбор источника данных.

Источники не смешиваются между собой. Например, события и свечи `binance_klines` не объединяются с `chainlink_streams`.

### Direction

Фильтр направления события:

- `All` - все события;
- `Bullish` - движение или сигнал вверх;
- `Bearish` - движение или сигнал вниз;
- `Neutral` - нейтральные события.

### Event type

Фильтр типа imbalance event:

- `Window move` - сильное движение за окно из N свечей.
- `Green streak` - серия зеленых свечей.
- `Red streak` - серия красных свечей.
- `Body anomaly` - тело свечи намного больше среднего тела в baseline.
- `Wick anomaly` - верхняя или нижняя тень намного больше средней тени в baseline.
- `Body/range` - тело занимает почти весь диапазон свечи.
- `Mean deviation` - close сильно отклонился от rolling mean.
- `Median deviation` - close сильно отклонился от rolling median.
- `Z-score` - доходность свечи статистически выбивается относительно baseline.
- `Percentile` - движение больше исторического percentile-порога.

### Window

Размер окна в свечах для оконных метрик и части imbalance-детекторов.

Например, `12 candles` на 5m таймфрейме примерно соответствует 60 минутам.

### Event window

Если включено, события фильтруются по конкретному `window_size`.

Если выключено, dashboard показывает события разных размеров окон.

### Severity

Минимальная сила события.

Чем выше значение, тем меньше событий останется в таблице и на графике.

`Severity` не является универсальной финансовой вероятностью. Для разных типов событий она считается по-разному:

- для `Window move` - абсолютный процент движения;
- для streak - абсолютный процент движения серии;
- для body/wick anomaly - кратность относительно baseline;
- для `Z-score` - абсолютный z-score;
- для percentile - абсолютное движение свечи.

## Candlestick chart

Основной график показывает 5-минутные свечи выбранного актива, источника и периода.

### Зеленая свеча

`close > open`.

### Красная свеча

`close < open`.

### Нейтральная свеча

`close == open`.

### Горизонтальная пунктирная линия

Текущая линия цены на графике.

### Маркеры событий

Маркеры показывают найденные imbalance events. На график выводится ограниченная выборка наиболее сильных событий, чтобы не перегружать интерфейс.

### Selected candle

При клике по свече выбирается конкретная свеча. Ее данные используются в drill-down.

### Synced / loading

Показывает состояние загрузки dashboard:

- `loading` - данные сейчас запрашиваются;
- `synced` - текущая выборка загружена.

## Window metrics

Панель считает метрики по последнему окну из `Window` свечей.

### Change

Процентное изменение от `open` первой свечи окна до `close` последней свечи:

```text
(last.close - first.open) / first.open * 100
```

### Range

Диапазон окна в процентах:

```text
(max_high - min_low) / first.open * 100
```

### Max high

Максимальный `high` внутри окна.

### Min low

Минимальный `low` внутри окна.

### Green / Red

Количество зеленых и красных свечей внутри окна.

### Body/range avg

Среднее отношение тела свечи к полному диапазону свечи:

```text
abs(close - open) / (high - low)
```

Высокое значение означает, что свечи чаще закрываются близко к краю диапазона. Низкое значение означает больше теней и меньше направленного тела.

## Latest candles

Таблица последних свечей выбранной выборки.

### Time

Начало 5-минутной свечи.

### Open

Цена открытия свечи.

### High

Максимальная цена свечи.

### Low

Минимальная цена свечи.

### Close

Цена закрытия свечи.

### Ticks

Количество realtime ticks внутри свечи.

Для Binance historical и Chainlink Candlestick historical значение обычно `0`, потому что эти источники пишут готовые OHLC-свечи, а не raw ticks.

Для Chainlink accumulated realtime `Ticks` показывает, сколько latest reports попало в локальную свечу.

## Imbalance events

Таблица событий дисбаланса.

### Time

Начало события или окна события.

### Type

Тип события из imbalance engine.

### Dir

Направление события:

- `Bullish` - вверх;
- `Bearish` - вниз;
- `Neutral` - нейтрально.

### Severity

Сила события. Интерпретация зависит от типа события.

### Move

Процент движения, если он применим для события.

## Heatmap

Heatmap показывает распределение событий по активам и типам.

### Строки

Строка соответствует активу: BTC, ETH или SOL.

### Ячейки

Каждая ячейка соответствует одному типу события.

### Число в ячейке

Количество событий этого типа по активу.

### Интенсивность цвета

Чем ярче ячейка, тем больше событий относительно других ячеек в текущей выборке.

### Малое число под count

Средняя severity по событиям в ячейке.

## Drill-down

Панель показывает детали выбранной свечи.

### Candle ID

Внутренний ID свечи в базе.

### Time

Время начала выбранной свечи.

### Close

Цена закрытия выбранной свечи.

### Ticks

Количество realtime ticks внутри свечи.

### Feature grid

Расчетные признаки свечи:

- `body` - размер тела свечи;
- `upper wick` - верхняя тень;
- `lower wick` - нижняя тень;
- `full range` - `high - low`;
- `body percent` - тело свечи в процентах от `open`;
- `range percent` - полный диапазон свечи в процентах от `open`;
- `body to range ratio` - доля тела в полном диапазоне;
- `candle return percent` - изменение от `open` к `close`;
- `close return percent` - изменение от предыдущего `close` к текущему `close`, если доступно.

## Export CSV / JSON

### CSV

Экспортирует текущие свечи и события в табличном виде.

### JSON

Экспортирует текущие фильтры, свечи, события и window metrics.

## Практическое чтение dashboard

1. Сначала выбери источник.
2. Проверь `Source status`, чтобы понимать полноту данных.
3. Выбери актив и период.
4. Посмотри верхнюю карточку: цена, изменение, количество свечей и событий.
5. Проверь график и маркеры.
6. Посмотри `Window metrics`, чтобы понять последнее окно.
7. Используй таблицу `Imbalance events`, чтобы найти конкретные экстремальные движения.
8. Кликни по свече и проверь `Drill-down`.
